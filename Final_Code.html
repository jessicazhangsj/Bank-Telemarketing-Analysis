This part will conduct deep learning method for this dataset. For nerual networking processing, we used multiple layers mapping with ReLU and Sigmoid. The reason using ReLU is because the target value "y" is a binary value where eighter "0" or "1" in its output. To prepare for this modeling, numerical variables such as age, balance, day, campaign, pdays and previous should be standarlized before fitting the model.¶

classes = np.unique(y_train)
weights = compute_class_weight(class_weight = "balanced", classes = classes, y = y_train)
class_weight_dict = dict(zip(classes, weights))

model = Sequential([
    Input(shape = (X_train.shape[1],)),
    Dense(32, activation = "relu"),
    Dense(1, activation = "sigmoid")
])

model.compile(
    optimizer = "adam",
    loss = "binary_crossentropy",
    metrics=[
        "accuracy",
        tf.keras.metrics.AUC(name = "auc"),
        tf.keras.metrics.Precision(name = "precision"),
        tf.keras.metrics.Recall(name = "recall")
    ]
)

III. Conclusion¶

The model achieved an overall test accuracy approximate to 80%, this is an acceptable general predictive performance. However, because the dataset is imbalanced, the class specific metrics provide a more meaningful evaluation. The model performed much better on the majority No class than on the minority Yes class. For the Yes class, recall reached 0.66, showing that the model was able to identify a moderate proportion of actual subscribers, but precision was only 0.31, means that many predicted positive cases were incorrect. This suggests that the model is more useful for broad screening of potential subscribers than for highly accurate positive targeting.¶
